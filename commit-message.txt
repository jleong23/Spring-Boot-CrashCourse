REST API + Spring Boot:
- @GetMapping → Handle GET requests to retrieve data
- @PostMapping → Handle POST requests to create data
- @RequestBody → Convert JSON request body into a Java object
- Content-Type: application/json → Specify JSON request format
- POST /api/v1/software-engineers → Create a software engineer via REST API
- getAllSoftwareEngineers() → Retrieve all engineers through the service
- insertSoftwareEngineer() → Pass engineer data to the repository
- repository.save() → Save an entity to the database using JPA
- Controller → Handles HTTP requests
- Service → Manages application logic
- Repository → Handles database operations
